This directory holds reference PCM audio templates for the Speech Practice game.
Each file should be a raw 16kHz 16-bit mono PCM recording of the correct pronunciation.

Expected files:
- water_ref.pcm
- milk_ref.pcm
- bread_ref.pcm
- help_ref.pcm
- mama_ref.pcm
- baba_ref.pcm

The app generates synthetic fallback templates when these files are not found.
